# Unsent: The Micro-Confession Sprint

A tiny Node program that writes one two-part micro-confession — a `To:` line naming who it was meant for, and the unsent line itself — to `/output/entry.txt`.

Built for the [make.fun](https://make.fun/competitions/u-boothlord-unsent-the-micro-confession-sprint-8c6596ba) bounty "Unsent: The Micro-Confession Sprint".

Referral code: `7z4nfrpv`

## Run

```sh
node main.ts
```

The entry is written to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
